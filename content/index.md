A Quartz site for organizing and publishing Obsidian scripts, snippets, and automation notes.

## Getting started

- Drop Markdown notes into `content/` (or symlink your Obsidian vault with `npx quartz create --strategy symlink`).
- Use folders and tags to group scripts by purpose (Templater, Dataview, QuickAdd, custom JS, etc.).
- Preview locally with `npx quartz build --serve`.
