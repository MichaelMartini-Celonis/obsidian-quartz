# Conference paper sources for the paper harvesters.
#
# Each conference is harvested by a dedicated script that discovers the accepted
# papers, decides which have a freely/legally downloadable copy, and drops the
# PDFs into Inbox/<conf-year>/ (from where import-downloads.py files them into
# Literature/). Lines starting with '#' are ignored.
#
# Format (one entry per block):
#   conf   = <short name>
#   years  = <years covered>
#   list   = <URL(s) of the accepted-papers listing>
#   method = <how open-access / preprint availability is determined>
#   script = <harvester in scripts/>
#   out    = <Inbox output folder>

conf   = SIGMOD
years  = 2024, 2025, 2026
list   = DBLP TOCs — PACMMOD vols 1-4 (research, filtered to "SIGMOD Conference <year>", PODS excluded)
         + conf/sigmod/sigmod<year>c (industry / demo / tutorial / etc.)
method = arXiv API title match (fuzzy title ratio + author-surname confirmation)
script = scripts/sigmod-arxiv.py   (gather | match | download | all)
out    = Inbox/sigmod-arxiv/<year>/<track>/

conf   = ICDE
years  = 2021, 2022, 2023, 2024, 2025, 2026
list   = DBLP TOC XML — conf/icde/icde<year> (2021–2025; research+companion mixed
         as track "main")
         + https://icde2026.github.io/accepted-papers.html (research) and sibling
         pages ia-papers / demo-papers / tkde-papers / deft-papers / phd-papers
         for 2026 (not yet in DBLP)
method = parse DBLP / accepted-papers HTML for title/authors; resolve PDF via
         (1) arXiv title match, (2) Unpaywall DOI lookup when DBLP provides a
         DOI. IEEE proceedings themselves are paywalled.
script = scripts/icde-arxiv.py     (gather | match | download | all)

conf   = PVLDB / VLDB

         __NEXT_DATA__.props.pageProps.groupedIssues with a direct volN/p*.pdf)
method = the proceedings are fully open. Front-matter PDFs are dropped. No arXiv

         embedded images with zero extractable characters — the newest edition,
         and the only unusable one. Its page is 5449x5858 pt (76x81 inches), so
         the OCR stage's 2200 px max edge cannot rescue it either. `text_chars`
         is recorded per version in the report so this is visible at fetch time
         rather than after indexing reports the document empty. Skipping is
         decided by whether the exact versioned filename is already held.
script = scripts/atlassian-schema.py   (gather | download | all)
out    = Inbox/jira-schema/   ->  Literature/Source Systems Knowledge/Atlassian/
note   = routing is by drop-zone subfolder (COHORT_FOLDERS), because a
         SchemaCrawler export's cover page reads "Generated by: SchemaCrawler
         8.16 / Database: H2" and the topic rules take it for a database paper.
         Do not run search/retitle.py over this folder: an LLM title taken from
         the first page drops the Jira version and names the host database
         instead ("PostgreSQL Database Schema Documentation" for the 6.1 dump).

# Not a conference; a curated cohort assembled to test whether anyone simulates
# artifact-centric (Hull) or Guard-Stage-Milestone models the way BPMN models
# are simulated. See SOURCES.md 3d. This literature is unusually badly served by
# the open-access graph, so the archives below are enumerated as resolvers.

conf   = Artifact-centric & declarative cohort (80 works, six cohorts)
years  = 2003-2026
list   = enumerated in scripts/gap-artifact-centric.py, from the concepts the
         `artifact-centric-simulation` topic map (scripts/gap-topics.json)
         returned MISSING or thin. Cohorts: foundations, verification,
         enactment, declarative-simulation, paradigm-comparison,
         object-centric-bps.
method = every open location for a work is collected before any is declared
         missing (candidates() returns a list, not the first hit), then each is
         tried in turn: explicit override -> arXiv -> OpenAlex -> Unpaywall ->
         Semantic Scholar -> CEUR volumes -> author pages -> EPrints -> DBLP
         `ee` links. The list form is the point: OpenAlex and Unpaywall answered
         for three Hull/Su papers with dl.acm.org 403s while plain PDFs sat on
         Su's page.
         Title matching against a page index requires either an exact match,
         containment within a quarter in length, or -- for a pure fuzzy ratio --
         agreement on every word of six characters or more. Without that last
         rule Reijers' page answers for BOTH Fahland "Issue of Understandability"
         and "Issue of Maintainability" (ratio 0.91, 47-character shared
         prefix), and it hosts only the first.
script = scripts/gap-artifact-centric.py [all|<cohort>] [--dry-run]
out    = Inbox/gap-artifact-centric/ -> Literature/Process Modeling/ (flat, via
         COHORT_FOLDERS; NOT a subfolder of its own -- the gap audit scores a
         concept partly on whether a path names it, so a folder called
         "Artifact-centric and Declarative" would report all 47 papers as
         holdings of both terms)
note   = 47 of 80 obtained, 15 already held, 16 with no open copy anywhere.
         The unreachable 16 are the primary sources, not the periphery: the
         WS-FM 2010 GSM paper, Hull's ODBASE 2008 survey, the Damaggio/Hull/
         Vaculin equivalence result, Bhattacharya et al. BPM 2007, Barcelona,
         the Marin/Hull/Vaculin CMMN survey. All IBM Research work whose author
         copies went with the retired researcher.watson.ibm.com pages.

# --- Shared helper -----------------------------------------------------------

# above. Imported by the harvesters in this file.
